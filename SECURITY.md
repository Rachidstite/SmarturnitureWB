# Security Policy

## Supported versions

SmartFurnitureWB is under active development. Security reports should include the repository revision and FreeCAD version used to reproduce the issue.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

When possible, report privately through GitHub's repository security reporting mechanism. Include:

- A concise description of the vulnerability
- Reproduction steps or a minimal proof of concept
- Affected files or components
- FreeCAD version and operating system
- Expected and observed behavior
- Any relevant logs

Manufacturing and CNC-related security issues should also identify whether the issue can affect generated machining data, exported files, or validation results.

## Scope

SmartFurnitureWB is a FreeCAD workbench. Security reports involving generated manufacturing data should distinguish software-security issues from ordinary manufacturing-rule or geometry defects.
