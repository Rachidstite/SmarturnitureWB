# Product Roadmap

This roadmap defines the product phases for SmartFurnitureWB after the platform foundations are complete.

## Phase 1 - Commercial Pilot

Focus:

- cabinet engineering
- manufacturing outputs
- assembly documentation
- quotation
- profitability
- user workflow
- production visualization
- decision projection contract for release review

Goal:

- support the first paying furniture manufacturer on real cabinet projects

Supporting documents:

- [Commercial Pilot Readiness](./Commercial_Pilot_Readiness.md)
- [Commercial Pilot Backlog](./Commercial_Pilot_Backlog.md)
- [Commercial Pilot KPIs](./Commercial_Pilot_KPIs.md)
- [Decision Projection Contract](./Decision_Projection_Contract.md)

## Phase 2 - Customer Validation

Focus:

- workshop and factory feedback
- release package usability
- documentation clarity
- warning quality
- output completeness

Goal:

- confirm the pilot workflow works in real customer environments

## Phase 3 - Factory Expansion

Focus:

- ERP integration
- MES integration
- procurement planning
- scheduling
- shop-floor coordination

Goal:

- expand the validated pilot into operational factory systems

## Phase 4 - Enterprise / SaaS Readiness

Focus:

- multi-tenant operation
- APIs
- integrations
- enterprise governance
- deployment scaling

Goal:

- support broader enterprise distribution after pilot and factory validation

## Roadmap Rules

- Phase 1 must stay centered on cabinet engineering, manufacturing outputs, assembly, quotation, and user workflow
- Phase 2 must be driven by real workshop and factory feedback
- Phase 3 may include ERP, MES, procurement, and scheduling only after pilot validation
- Phase 4 may include SaaS, multi-tenant concerns, and enterprise integrations only after factory expansion is validated
