# Commercial Pilot KPIs

These KPIs define when SmartFurnitureWB is ready for the first paying furniture manufacturer to use it on real cabinet projects.

## 1. Core Efficiency KPIs

- Full cabinet project designed in under 15 minutes
- Project review completed without manual reconstruction of the model
- Release package generated without critical missing-output warnings

## 2. Manufacturing Output KPIs

- Cut list generated for 100% of panels
- CNC evidence generated for all machining-required panels
- Edge banding list generated for all exposed edges
- Hardware list generated for all required hardware
- Assembly instructions generated for 100% of pilot projects
- QA checklist generated for 100% of pilot projects

## 3. Commercial Output KPIs

- Quotation generated for 100% of pilot projects
- Profitability summary generated for 100% of pilot projects
- Commercial risk warnings generated when needed
- Customer package generated for 100% of pilot projects

## 4. Visualization KPIs

- Production Visualization Coverage above 95%
- Visualization matches production evidence for the supported pilot families
- No visualization of unsupported prototype hardware in release mode

## 5. Quality Gate KPIs

- Zero known critical manufacturing blockers at release
- Zero unresolved geometry-to-manufacturing mismatches on pilot projects
- Zero unreconciled cost/commercial contract violations on pilot projects

## 6. Readiness Interpretation

Target meaning:

- 100% on the output KPIs means the pilot project can be prepared without manual reconstruction
- above 95% visualization coverage means the release review is trustworthy enough for pilot use
- zero critical blockers means the release package can be treated as operationally credible
